# CV

Markdown-based CV. The single source of truth is [`src/cv.md`](src/cv.md).

It is rendered and published by GitHub Actions on every push to `main`,
as a web page and as a PDF.

Live version: https://daniellorente20.github.io/cv/

PDF: https://daniellorente20.github.io/cv/cv.pdf

JSON: https://daniellorente20.github.io/cv/cv.json

## Editing

Edit `src/cv.md` and push to `main`. That is the whole workflow.

Styling lives in [`src/theme.css`](src/theme.css).
